Bornhack CTF 2026 - Challenges
==============================
This is the private repository for challenges for Bornhack CTF 2026


How to make a challenge
-----------------------
0. Flag format: `BHCTF{}`
1. Create a directory in `./challenges`
2. Popluate with challenge source code
3. Update `challenge.yaml` describing the challenge, if dynamic
